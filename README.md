## Overview

This project extends **CreOn** — an integrated OWL2 ontology of creativity theories — by applying it to a concrete dual-cultural artifact: the films *The Devil Wears Prada* (2006) and its sequel (2026), separated by twenty years.

The core contribution is the modeling of **opera aperta** and **fruition**: how the same `CreativeProduct` acquires different meanings across different reception contexts, driven by changes in `CreativityPress`.

### Open questions addressed

Two open research questions from the CreOn README motivated this project:

- *How does opera aperta function beyond the production/fruition binary?*
- *How does CreativityPress reshape a PersonalProcess when the same creative agents return two decades later?*

## New Classes (T-Box)

The four core new classes introduced by this project:

| Class | Parent | Purpose |
|---|---|---|
| `:FruitionContext` | `creon:CreativitySituation` | Models a reception event — when and how a film is experienced by an audience |
| `:ReceptionShift` | `dul:Event` | Models a change in interpretive frame across two FruitionContexts |
| `:MediaIndustryPress` | `creon:CreativityPress` | Structural changes in media industry (streaming, print decline) |
| `:SequelProcess` | `creon:PersonalProcess` | A creative process that revisits a prior PersonalProcess |

Plus 33 additional subclasses covering fruition types, shift types, press types, interpretive frames, film roles, and audience types.

Load `creon_tdwp_populated.ttl` into a SPARQL endpoint (e.g. Apache Jena Fuseki) and run the queries from `creon_tdwp_sparql.rq`.

## Opera Aperta — Key Finding

The same film (*The Devil Wears Prada*, 2006) has been interpreted through at least three distinct conceptual frames across its reception history:

```
2006 → "Ambition and the price of success"     [TheatricalFruitionContext]
         ↓ triggered by #MeToo (2017)
2017 → "Workplace abuse and toxic leadership"  [CriticalFruitionContext]
         ↓ triggered by StreamingEra (2024)
2026 → "Nostalgia for the print media era"     [StreamingFruitionContext]
```

The `CreativeProduct` is ontologically stable. The `FruitionContext` evolves.
